# Employee Management System

## About Project
This is a simple C++ project for managing employee records.

## Features
- Add Employee
- Display Employee
- Search Employee
- Update Employee
- Delete Employee
- Salary Details

## Technology Used
- C++
- Object Oriented Programming

## How to Run
1. Open EmployeeManagement.cpp
2. Compile the program.
3. Run the program.
4. Select an option from the menu.

## Project Objective
The main objective of this project is to manage employee information easily using C++.
